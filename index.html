      Then

      1. Add a repository secret named ANTHROPIC_API_KEY. How to create a repository secret.
      2. Commit the files above at the paths shown.
      3. Create a label named re-review in the repository (any colour). The ai-scan label is created for you on the first scan that opens an issue.

      Prefer the terminal? In your repository run pipx install git+https://github.com/simpli-software/simpli-review then simpli-review init. It asks the same questions and writes these files.
